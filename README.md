# Number Sprint

A quick mental-arithmetic game in a single HTML file.

- Pick any mix of + − × ÷ and a level (Easy, Medium, Hard)
- Race a 60-second sprint or practise 20 questions
- Type on your keyboard or tap the on-screen keypad
- Streak bonuses, saved best scores, and a list of missed questions to practise

## Play

Open `index.html` in any browser. No build step or dependencies.
